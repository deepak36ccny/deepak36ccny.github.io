# Deepak Kumar Profile Website

## Files
- `index.html`: Main website page
- `style.css`: Website styling
- `Deepak_Resume_CCNY.pdf`: Resume PDF

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Click **Save**.
7. Wait a few minutes and open `https://yourusername.github.io`.

Before publishing:
- Replace the LinkedIn placeholder in `index.html` with your real LinkedIn URL.
- Review the email address and all public information.
